# focus-desktop v0.3.0 — 前端重设计 + 稳定性强化实施计划

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** 修复首页右下空洞、重做番茄钟信息表达、Tab 条升级为真正的浏览器式（含 PDF 多开）、音量控件精致化，并补 5 项稳定性强化。

**Architecture:** 纯 UI 层改造为主（MainWindow.xaml / PomodoroControl / Tab 条构建器），Web 层加动态 Tab 与 WebView2 进程崩溃自愈，不动锁定/恢复/watchdog 等已验证的可靠性层。

**Tech Stack:** WPF (net10.0-windows) + WebView2 (WinForms Host)，无新依赖。

---

## 现状诊断（源码核实，非猜测）

1. **右下空**：`MainWindow.xaml:109-113` 右列 Grid 两行全是 `Auto`，卡片 `Width=320` 固定 + 顶部对齐 → 卡片下缘到屏幕底（2560×1600 屏约 500+ 逻辑 px）全空。
2. **番茄钟看不懂**：`PomodoroControl.cs` 状态行 idle 时显示"第 0 轮 · 准备开始"（无意义）；开始/暂停/重置三键永远并列（状态机应有 3 套按钮态）；环形圈没有阶段语义（专注/休息一个色）；没有 work/break 规则说明。
3. **Tab 条不像浏览器**：`MakeTabButton()` 生成的是普通圆角按钮；无关闭按钮、无激活态视觉锚点；PDF 是单一固定 Tab（`MainWindow.xaml.cs:177`），`OpenFile` 复用 `pdf` Tab → 第二个 PDF 顶掉第一个。
4. **音量粗**：`MainWindow.xaml:52-56` 🔊emoji + 默认 Slider Width=90，未定制 Template。
5. **稳定性缺口**（review 发现）：
   - WebView2 `ProcessFailed` 事件未订阅 → 渲染进程崩溃 = 网页区白屏到重启；
   - 启动急切创建 5 个 WebView2 控件 → 启动慢 + 崩溃面大；
   - `Console.Beep()` 在无声卡/虚拟机可能抛异常（番茄钟完成提示在 UI 线程）；
   - 文件列表用 `ItemsControl` 无虚拟化 + UI 线程枚举目录 → 大目录/网络盘卡 UI；
   - WebView2 Runtime 缺失时只写 crash log，界面无提示。

### Task 5: WebView2 进程崩溃自愈（稳定性 #1）

**Files:** Modify `src/focus-desktop/Services/WebTabService.cs`

**改动：**
- 订阅 `CoreWebView2.ProcessFailed`：
  - `FrameProcessFailed`/渲染进程级：对该 Tab 执行 `RecreateTab(id)`（销毁控件→原 URL 重建）；
  - `BrowserProcessExited`/`ProcessFailed` 主进程级： Dispose 整个 environment，全部 Tab 按原 URL 依次重建，界面显示「网页进程已重启，正在恢复…」横幅；
- 重建失败兜底：Tab 条保留但点击时提示重试。

**验证：** 手动测试脚本：锁定外用 `taskkill /f /im msedp.exe`（WebView2 子进程）杀渲染进程 → 对应 Tab 自动重载不出白屏。

## 风险与权衡

- **PDF 多开内存**：每个 WebView2 控件共享同一 browser process，增量约 30-60MB/Tab，学习场景同时 2-4 个 PDF 可接受；不设上限（用户自律），文档里注明。
- **懒加载 vs 首点延迟**：首次点开某站多 ~1-2 秒（环境已建，仅建控件），换取启动提速与崩溃面缩小——值得。
- **Tab 懒加载与 smoke 兼容**：smoke 分支代码路径与正常分支分叉，需小心别让 smoke 测不到真实路径——改为逐个 Activate 覆盖。
- **Ctrl+Tab 快捷键**：确认钩子白名单放行（当前钩子只拦 Win/Alt+Tab/Alt+F4/Ctrl+Esc），Ctrl 系不受影响。
- **不动锁定/恢复层**：以上全部是 UI/Web 层改动，锁定、watchdog、退出链路零触碰——13/13 验收是安全网。

## 明确不做（YAGNI）

- Tab 拖拽排序、收藏夹、历史记录、多窗口——学习 kiosk 用不上；
- 番茄钟统计/打卡——用户明说第一版不要；
- 音量 Flyout 弹窗——胶囊内联已够，少一个弹窗层少一分 airspace 风险。
