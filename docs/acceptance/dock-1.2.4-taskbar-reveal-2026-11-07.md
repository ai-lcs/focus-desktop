# Dock 1.2.4 鼠标触底修复验收

2026-11-07，本机主屏 2560×1600、200% 缩放。仅修改 `new` 分支新版。

## 原因与修复

1.2.3 为释放底部占位临时启用了任务栏自动隐藏，但 Explorer 仍可在鼠标触底时再次显示任务栏窗口。单次隐藏不足以阻止这一行为。

1.2.4 在专注期间为任务栏设置零透明度，系统再次显示该窗口时仍不可见，且鼠标命中穿透。原有分层样式、透明度、色键及标志保存在任务栏 HWND 属性中，正常退出和看门狗均按原值恢复，成功后删除属性；窗口重建不会继承旧 HWND 属性。不能安全读取原透明样式时取消进入专注。依据：[Microsoft Layered Windows 的显示与命中规则](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features)。

回归还捕捉到系统通知使左侧栏短暂偏移。现在在注册栏的 `WM_WINDOWPOSCHANGING` 中保留已批准的边界，防止位移先显示出来；服务自身重新布局仍可更新边界。

## 完成的验收

| 场景 | 最终结果 |
| --- | --- |
| 实际鼠标触底停留 | 连续 5 秒，45 次采样均保持任务栏 alpha=0，未命中任务栏；全屏画面无任务栏 |
| 实际底边左右移动 | 原生消息记录 x=592、1392、2192，y=1598；各点均保持隐藏并穿透 |
| 实际底边点击 | 测试窗口收到 `WM_NCLBUTTONDOWN`，坐标 `(1392,1598)`；任务栏未获得前台或命中 |
| 屏幕最后一行 | 每个上述阶段另核对物理 y=1599 的原生命中，均未落到任务栏 |
| 系统主动显示任务栏 | 自动切换回归强制显示 20 次，透明与穿透保持；最终包正常退出及运行中断回归各再显示 20 次，固定栏边界保持 |
| 切换连续性 | 同轮 160 次内部切换、40 次可丢弃外部窗口往返通过；页面、草稿、Cookie、计时和 Hard Focus 状态保留 |
| 正常退出 | 最终包安全退出助手返回 0；原任务栏设置、分层样式及工作区完全恢复；临时属性和恢复标记清理 |
| 启动中断 | 任务栏隐藏后、注册 AppBar 前中断精确测试 PID；看门狗恢复通过 |
| 运行中断 | 两栏建立并主动显示任务栏后中断测试实例；看门狗恢复通过 |
| 退出后的可用性 | 全屏截图确认任务栏显示；物理 `(1392,1599)` 重新命中任务栏，临时分层样式为 false，快照为 0 |
| 最终二进制逻辑检查 | Dock 85/0、URL 60/0；卸载数据策略 10 项及静态检查通过 |

鼠标操作通过受支持的 Computer Use API 在可丢弃窗口执行；移动使用定位并发送微小滚轮输入，点击有原生消息记录。工具在本机按整数逻辑坐标定位，实际最下可定位点为物理 y=1598；y=1599 的验证是原生命中测试，未混称为该物理像素的实际鼠标操作。

本轮未操作 Codex、QQ 音乐或 VS Code 的内容，未执行安装包。覆盖范围是本机鼠标触底、固定栏边界及退出恢复，不代表所有系统版本、Explorer 重启或多屏场景均已验证。
