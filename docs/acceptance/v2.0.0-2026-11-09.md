# Focus Desk 2.0.0 验证记录

2026-11-09。本版仅调整产品命名、安装与卸载策略，以及相关说明；软件切换、专注与恢复机制沿用 1.2.5。

- 产品 Release 构建成功，0 警告、0 错误。
- 卸载授权生产判据 10 项及安装器静态检查通过。所有卸载入口无条件传入 `--prepare-uninstall --remove-user-data`，不再有保留数据的选择；清理仍在应用助手持锁期间完成。
- 检查安装标识沿用 1.2.x；新安装默认目录、产品名和安装包名不带 Dock；升级清理旧安装器创建的 Dock 入口。
- 最终安装包由 Inno Setup 编译；构建脚本核对便携包与安装 payload 的程序哈希相同，并检查便携包只有程序、portable.flag 和第三方许可说明。
- 最终 ZIP 内运行逻辑自测，并核对程序版本和提交号；上传为草稿后重新下载三个附件，逐个核对完整哈希，完成后才发布正式版与 Latest。包级执行结果、源码和附件指纹保存在私有发布证据目录。

没有在用户正在使用的安装环境中运行清理数据的卸载测试，也没有宣称完整安装／升级／卸载矩阵已通过。账户不符、占用和恢复不确定等拒绝清理行为保持原有保护。学习资料位于独立目录时不在应用数据删除范围内。

1.2.5 的正式桌面切换与恢复证据见 [前版记录](v1.2.5-2026-11-09.md)；本轮未重跑多屏、独占全屏或长时间压力验证。
