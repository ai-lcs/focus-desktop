# Dock 1.2.3 本机验收记录

后续用户实测发现鼠标触底仍会唤出系统任务栏；本记录未涵盖该场景，1.2.3 已由 [1.2.4 触底修复版](dock-1.2.4-taskbar-reveal-2026-11-07.md)替代。下文保留为当时的历史证据。

2026-11-07。源码位于 `new`，本轮针对底部空隙、两栏常驻、启动/退出显示顺序、切换连续性及桌面恢复完成本机验收。尚未提交或发布 1.2.3，不替代其他机器和安装矩阵的验收。

## 本次修复

- 隐藏系统任务栏时同步释放它的屏幕占位，并在会话记录中保存原任务栏设置。正常退出或看门狗恢复后核对原设置和原工作区，确认后才清理恢复标记。
- 左侧 Dock 和顶部原有控件保持常驻。外部主窗口按 DWM 可见边框适配剩余区域，必要的所属弹窗保留自身尺寸。不再注册返回热键。
- 启动时先完成布局，再解除系统合成层的临时隐藏；退出时先隐藏，再撤销固定栏，避免把中间尺寸展示出来。采用 Windows 的 [DWMWA_CLOAK/CLOAKED](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute) 设置及读取能力；窗口过渡关闭参数仅用于设置，未将其误作可读取属性。
- 已运行的名单内主窗口在桌面变更前保存原位置；仅恢复本会话实际适配过且窗口标记仍匹配的窗口。捕获与释放互斥，销毁后复用的 HWND 不沿用旧记录。
- 顶部栏释放可重复调用。正常退出助手等待上限由 2.5 秒调整为 10 秒，容许本机正常清理完成；仍不会强杀无响应或有草稿的应用。

## 证据位置与方法边界

私有证据目录：`%EVIDENCE_ROOT%\2026-11-07-acceptance`。

- `qqmusic-restoration-final.log`、`fixture-observed.log`：原生集成切换、连续性、位置还原及耗时。切换通过直接调用产品处理函数执行；用受支持的 Computer Use 向合成主窗口发送 F6 建立真实前台输入，未操作 QQ 音乐的播放、文件或关闭。这不等于人工鼠标往返验收。
- `Normal-result.json`、`CrashEntering-result.json`、`CrashActive-result.json` 及对应 `*-trace.json`：最终包的实际生产启动/恢复路径。目标采样间隔为 10 ms，实际时间戳在文件中；这是窗口合成状态/几何检查，不是新录制的 60 fps 逐像素流畅度证明。正常退出走产品的安全退出消息处理路径，不经过退出语的鼠标输入界面。
- `Normal-screenshot-path.txt`、`CrashActive-screenshot-path.txt` 记录最终包的临时截图路径。QQ 音乐画面检查截图为 `%TEMP%\codex-shot-2026-11-07_20-04-38.png`，已核对顶部、左侧和屏幕底边；其后位置保存时序的改动不改变布局计算。
- `accepted-source-manifest.json`、`delivery.json`、`protected-comparison.json`、`legacy-registry-comparison.json`：源码与交付二进制指纹、入口及旧版核对。保护快照中还包含历史 Dock 1.2.0 的早间状态；它的数据/入口与早间有差异，不能据此声称所有历史 Dock 目录未变。成熟旧版上述核验均通过，本轮未回写该历史 Dock 目录。
- 用户旧视频共 1494 帧，已提取全帧指标并检查开头、结尾和启动关键帧；早期证据留在 `2026-11-07-video-layout`。OBS 自身最小化/最大化与 Focus Desk 启退分开判断。

验收中曾出现工作区被 Shell 重置、重复释放顶部栏、保存位置过晚和退出等待时间不足，均修正后复验。无实际输入的后台合成运行曾被 Windows 拒绝前台激活，未将其计为通过。失败/中间候选记录保留，交付只采用最终包。

尚未覆盖：真实 Codex/VS Code 鼠标操作、保存/登录等第三方弹窗完整矩阵、睡眠/显示器/DPI 动态变化、多屏、独占全屏、长时间压力，以及隔离环境内安装/升级/卸载矩阵。异常恢复的通过范围是系统任务栏、AppBar、工作区和恢复标记；外部应用自身状态及异常退出后的原窗口位置恢复未作保证。
