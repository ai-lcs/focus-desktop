# Focus Desk Dock 1.2.1-rc.1 — 新版候选

历史记录：该候选 Release 已在 2026-11-08 的整理中移除，同名 Git 标签保留。当前主版本见 [v1.2.4](v1.2.4.md)，下文描述当时的功能与验证范围。

这是带外部软件 Dock 的开发候选，以 GitHub Pre-release 发布，不替换既有 Latest。源码位于 `new` 分支，标签为 `dock-v1.2.1-rc.1`；程序内部版本为 1.2.1。

不需要外部软件 Dock 的用户可继续使用 `main` 分支对应的旧版 [v1.0.8](https://github.com/ai-lcs/focus-desktop/releases/tag/v1.0.8)。本次不修改旧分支、旧标签或旧版附件。

## 本版变化

- 正式专注隐藏 Windows 任务栏，主界面与左侧 Dock 使用显示器完整高度，覆盖任务栏隐藏后留下的底部预留区域。
- 增加 Ctrl+Alt+F10 返回 Focus Desk，保留网页、计时和 Hard Focus。快捷键被占用时取消进入 Dock 专注，关闭后释放；返回自身界面时避免全屏通知把 Dock 压到后台。
- 将前台窗口身份与 Shell 查询移出界面回调，忽略过期切换事件。长软件名按钮随内容增高，取消的切换请求不再继续主动启动应用。
- 同一 exe/AUMID 只允许一个入口；不承诺根据启动参数返回指定项目窗口。
- 新版使用独立安装标识、名称 Focus Desk Dock、默认安装目录 FocusDeskDock 和 `%LOCALAPPDATA%\focus-desktop-dock`。不自动读取或迁移旧版数据；拒绝覆盖已检测到的旧版或便携目录。
- 新版恢复、看门狗与卸载助手协调桌面和 profile 所有权；移除自动强杀 Explorer。数据清理由持锁助手执行，身份无法确认时拒绝清除。

## 验证范围

- Dock 自测 82/82、网址策略自测通过；生产卸载身份策略 10 项、会话/恢复逻辑 6 项及 profile 跨进程互斥检查通过。
- 本机 2560×1600、200% DPI 的独立合成配置下，正式模式验证了主界面/Dock 底边、任务栏隐藏、正常退出后的任务栏和工作区恢复。
- 使用本地合成网页和可丢弃全屏测试软件完成 160 次页面/文件页/首页切换与 40 次软件往返，网页实例、草稿、Cookie、自由计时起点与 Hard Focus 状态保留。
- 原生热键消息、主界面激活与 Dock 置顶状态确认了 Ctrl+Alt+F10 的实际输入返回。普通切换循环直接调用产品处理方法，不等同于真实鼠标验收。
- 一次最终源码对应测试中，软件切换 P95 约 35ms、最大约 42ms；本地页面/文件页/首页与返回流程 P95 约 63ms、最大约 109ms。结果仅代表本机、本地预热页面与合成测试软件，不代表真实网站、第三方软件、冷启动或任意负载。

## 尚未完成与使用边界

- 独立 Dock 的真实鼠标完整链路、Codex/QQ 音乐/VS Code 的逐项交互、真实保存/登录弹窗、长时间运行、多屏、其他 DPI 的真实 GUI 尚未全部验收。
- 最终 Setup 的安装、升级、卸载及不同账户矩阵未完成；本候选异常恢复全矩阵未完成。编译和逻辑检查通过不代表这些流程已验收。
- Dock 只提供确认名单中的入口，不是系统级程序封锁；不限制外部软件通过链接、终端等方式打开其他程序，也不约束外部浏览器的网站。
- 外部软件的窗口尺寸仍由 Windows 管理，未被强制拉伸；F11/独占全屏下 Dock 可见性不作普遍保证，可用返回快捷键。本机合成全屏测试不能替代所有第三方软件验证。
- 便携 ZIP 请解压到独立新目录，不覆盖旧版或现有数据目录。安装版使用新数据目录；便携版使用各自目录内的 `focus-desktop-data`。
- 旧版助手无法由新版源码自动修复。两版数据独立，但共享同一桌面的任务栏；不要同时运行专注，也不要在新版专注期间运行旧恢复/卸载操作。
