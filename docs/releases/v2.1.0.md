# Focus Desk 2.1.0

本轮为本机覆盖升级构建，尚未发布 GitHub Release。

- 软件选择合并开始菜单、Windows AppsFolder、桌面与已注册 App Paths，按程序路径或 AUMID 去重。支持名称搜索、多选、图标、已选数量；搜索和刷新保留已选入口。保留手动添加和跳过软件。
- TXT 使用白底深色字，支持严格 UTF-8、带 BOM 的 UTF-16/32，以及 GB18030/GBK 回退；显示识别编码，无法解码时明确报错。保留空行、制表符和长行换行阅读。
- Markdown 支持标题、列表、表格、代码块；禁用原始 HTML，阻止脚本和自动远程资源，图片仅从学习目录读取。链接仍按现有白名单校验。
- 软件栏左下角增加扬声器、太阳两个入口，打开并排的音量与亮度竖直滑条。保留独立静音按钮，点击外部或 Esc 收起；无软件栏时入口位于顶栏右侧。
- 内屏亮度通过 WMI 后台真实读写，拖动合并写入；不支持的屏幕禁用调节并说明原因。外接屏 DDC/CI 不在本轮范围。

升级沿用既有 AppId、安装目录与 `%LOCALAPPDATA%\focus-desktop-dock`，不重新配置、不改写冻结的软件名单。不先卸载；2.0.0 的卸载操作会清除账户数据。

Office 本轮只验证发现和选择，不包含 Word、PowerPoint 或 Excel 文档的内置预览。
