# Focus Desk 2.0.0 正式版

2026-11-09

这版统一使用 **Focus Desk** 这个名字。安装程序、桌面入口、开始菜单、卸载列表和窗口标题不再带 Dock 后缀；软件栏仍然可以在首次配置时跳过。

## 卸载就是重新开始

卸载会清除当前账户的应用配置、网页登录数据和日志，不再弹出“是否保留数据”的选择。静默卸载也执行相同的清理。

学习文件夹中的资料保留在原位置。程序仍会检查账户归属、文件占用及桌面恢复状态；无法安全清理时中止卸载并报告原因。

需要重新配置，卸载后再安装即可。只想更新程序，先正常退出，然后直接运行新版安装包，不需要先卸载。

## 下载

- `FocusDesk-Setup-2.0.0.exe`
- `focus-desk-portable-2.0.0.zip`
- `focus-desk-2.0.0-sha256.txt`

安装版可从 1.2.x 覆盖升级。安装身份和应用数据路径沿用原值，已有设置与网页登录状态可以继续使用；新安装默认目录为 `FocusDesk`。升级会清理安装器创建的旧 Dock 快捷方式，并建立 Focus Desk 和 Focus Desk 恢复入口。

便携版解压后运行，数据仍位于程序旁的 `focus-desktop-data`。便携版不注册卸载程序，移除时先正常退出，再删除程序目录；学习资料请存放在独立文件夹中。
