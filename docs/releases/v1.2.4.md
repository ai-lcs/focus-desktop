# Focus Desk Dock v1.2.4 — 新版主版本

发布日期：2026-11-08。

带软件 Dock 的新版从此作为主要维护版本，主线及默认分支为 `master`。原 `new` 分支改名为 `master`；无软件 Dock 的成熟旧版保留在 `main`，其最新版为 [v1.0.8](https://github.com/ai-lcs/focus-desktop/releases/tag/v1.0.8)。

## 本版变化

- 修复隐藏任务栏后底部仍有占位，普通外部窗口铺满固定栏以外的区域。
- 左侧 Dock 和顶部网页、学习文件、时间、音量、退出栏保持可用；删除返回热键，使用固定按钮返回。
- 修复鼠标触底使 Windows 任务栏重新浮出；专注期间保持不可见和命中穿透，正常退出及看门狗恢复时还原原样式。
- 防止系统通知使固定栏短暂位移；调整启动、退出显示顺序，避免展示中间尺寸。
- 在改变桌面前保存名单内已有窗口的位置，正常退出时尝试还原本会话调整过的窗口。
- 新版使用独立安装身份、默认目录和数据目录，不自动读取或迁移成熟旧版的数据。

## 下载

- 安装版：`FocusDesk-Dock-Setup-1.2.4.exe`
- 便携版：`focus-desk-dock-portable-1.2.4.zip`
- 校验清单：`dock-v1.2.4-sha256.txt`

两包包含同一程序二进制。便携包只含程序、`portable.flag` 和第三方许可说明，不含个人配置、学习资料或网页登录数据。程序包含 .NET 运行时；网页功能需要 Microsoft Edge WebView2 Runtime。

新旧版使用各自的目录和入口。学习文件夹可在首次设置时选择；新版安装版数据位于 `%LOCALAPPDATA%\focus-desktop-dock`，便携版数据位于程序旁的 `focus-desktop-data`。

## 验证范围

- 本机 2560×1600、200% 缩放下，实际底边停留、左右移动和点击通过；结合最后一行原生命中检查及 20 次任务栏主动显示回归，未出现任务栏浮出或抢占底边输入。
- 最终验收包的正常退出、启动中断和运行中断恢复通过；任务栏原样式、设置、工作区和恢复标记核对还原。
- 160 次内部切换、40 次可丢弃外部窗口往返，页面实例、草稿、Cookie、计时及 Hard Focus 状态保留。
- Dock 自测 85 项、URL 自测 60 项、卸载数据策略 10 项及静态检查通过。
- 发布构建核对已验收源码及程序指纹，上传后核对附件 SHA-256。

方法和鼠标坐标精度见[本机验收记录](https://github.com/ai-lcs/focus-desktop/blob/master/docs/acceptance/dock-1.2.4-taskbar-reveal-2026-11-07.md)。切换循环调用产品处理函数，不等于所有第三方应用的真实鼠标验收。

尚未完整覆盖多屏、独占全屏、所有第三方软件和保存/登录弹窗、长时间压力，以及隔离环境中的安装/升级/卸载矩阵。Dock 不约束外部软件自行打开其他程序或网页的行为。不要同时运行两版专注，也不要在新版专注期间运行旧版恢复、卸载助手。

## Release 整理

Releases 保留新版主版本 `v1.2.4`（Latest）和旧版最新版 `v1.0.8`。其余历史 Release 与附件先备份再移除；历史 Git 标签及源码继续保留，旧版分支和旧版发布附件保持不变。
