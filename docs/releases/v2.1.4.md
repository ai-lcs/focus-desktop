# Focus Desk 2.1.4

修复 WPS Office 套件启动器与实际文档窗口程序不同，导致已打开窗口无法识别、重复启动或误报超时的问题。窗口识别兼容 Windows 的长路径和 8.3 短路径；WPS 套件入口只匹配同一安装目录中已核对的文档程序及产品、厂商信息。

侧栏保留固定软件入口，未运行时点击启动，已有窗口时点击切换。删除“正在打开”提示。慢启动不再因短期未找到窗口而显示超时并强制跳回首页；等待期间的重复点击复用启动请求。观察结束不会关闭或终止外部程序，真实启动错误仍会显示。

包含 2.1.3 的独立音量、亮度面板与系统静音修复，以及 2.1.2 的番茄钟暂停修复。沿用安装身份和用户数据，统一覆盖更新。
