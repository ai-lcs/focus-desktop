# Focus Desk 1.2.5

2026-11-09

这版把“只用网页和资料”与“还要使用外部软件”放进同一个配置流程。首次设置时可以选软件，也可以直接跳过。跳过后不显示侧栏，仍保留左上角时间和右侧电量。

## 改了什么

- 侧栏会高亮当前软件，回到内置页面时高亮“返回 Focus Desk”。
- “返回 Focus Desk”现在直接回首页，在网页里点击也有效。
- 左上时间区与顶栏、侧栏的边界对齐；没有侧栏时，时间显示在顶栏最左侧。
- 电量显示加入电池轮廓和剩余填充，接电时加充电标识，无电池时显示“交流供电”。
- 新建标签的站点菜单紧贴“＋”下方弹出。
- 兼容已核对的学习通安装布局：桌面入口是启动器，实际窗口来自 `latest\cxstudy.exe`。保留原快捷方式和启动参数，只修正窗口匹配。
- README 重写，补充如何跳过软件、重新配置和保留数据升级。

软件名单与其他设置在首次确认后冻结。重新配置时，卸载选择清除应用数据，再重新安装；学习资料会保留，网页登录状态会清除。

## 下载

- `FocusDesk-Dock-Setup-1.2.5.exe`：安装版。
- `focus-desk-dock-portable-1.2.5.zip`：便携版。
- `dock-v1.2.5-sha256.txt`：附件校验值。

安装身份和应用数据目录沿用 1.2.x。退出正在运行的 Focus Desk 后再升级，安装版数据在 `%LOCALAPPDATA%\focus-desktop-dock`。旧 1.0.x 数据不自动迁移。

## 验证与边界

本机检查覆盖配置跳过、侧栏状态、时间区域、菜单位置、网页和计时连续性，以及任务栏隐藏和退出恢复。具体方法、结果和未测范围见 [验证记录](../acceptance/v1.2.5-2026-11-09.md)。

学习通兼容只针对已核对的启动器布局，不能据此保证所有软件、所有版本都可识别。多屏、独占全屏、各种第三方弹窗、长时间压力，以及一次性 Windows 环境中的完整安装／升级／卸载矩阵仍未全部覆盖。

后续开发集中在 `master`；旧分支删除前已备份，历史标签继续保留。
